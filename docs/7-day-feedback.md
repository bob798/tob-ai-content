# 发布后7天反馈记录

本模板无预填成绩。每篇从实际发布时间起连续记录7天；未发布期间全部为空。

- 稿件版本 / 实际URL：
- 发布时间与时区：
- CTA来源码：
- 承接人：
- 本篇假设：目标读者愿意分享涉及跨系统查询和人工判断的真实服务案例。

## 二、指标定义

| 层次 | 计入标准 | 不计入 |
|---|---|---|
| 曝光 | 平台显示的展示、阅读或浏览原始指标；记录指标名 | 推测曝光、把点赞数当阅读数 |
| 有效互动 | 目标读者提出具体问题、讨论限制、提供改进或描述实际场景 | 泛泛点赞、表情、无内容转发 |
| 业务交流 | 双向交流，并获得系统、工作流或人工判断节点等具体信息 | 只有“想了解”、单次关键词回复 |
| 商业线索 | 匹配目标团队，有明确问题和责任人，且同意进一步沟通 | 未表达合作意向、纯学习讨论 |

商业线索不是成交。机会与收入另行确认。有效互动、业务交流、商业线索可能是同一联系人在不同阶段的行为；分别统计事件与去重人数，不能简单相加。

## 五、7天复盘

1. 哪个平台带来了目标角色，而不只是曝光？
2. 哪类真实问题重复出现？是知识过时、跨系统查证、状态歧义，还是跨部门协调？
3. 哪些读者误以为项目已上线？需要调整哪一句或哪张图？
4. 哪些案例具备API、权限、历史工单与人工承接条件？
5. 哪个CTA更容易获得具体流程？没有回应可能是受众、分发或表达问题，不直接证明无需求。
6. 下一轮只改变一个变量：标题、开头、CTA或受众。记录变更理由。

转化率仅在分母定义一致时计算：业务交流人数/有效互动人数；商业线索人数/业务交流人数。分母为0记NA。小样本描述事实，不推断行业市场规模或成交概率。
