## 内容边界

退款案例为方案设计。仓库存在代码草案与Mock连接器，不代表已运行或已接入生产系统。160条是拟议测试计划，ROI与性能目标不是实测成果。核验快照与文档差异见[内容核验](docs/content-audit.md)。

## 使用方式

进入对应平台目录，取正文和PNG；小红书按01到04顺序上传。发布后记录实际URL、日期和反馈，未发布的内容不得标为已发布。

本库用于公开内容素材；客户真实身份、内部系统数据和商业线索不上传。公开仓库不等于已在社交平台发布。
